eBilal

Secure connection

Do this once on each phone, tablet or computer. Afterwards eBilal opens at https://ebilal.local/ with no "Not secure" warning, and you can install it as an app.

Your eBilal made its own security certificate when it was set up. Your device just needs to be told to trust it. That certificate can only vouch for devices on your home network, never for websites on the internet.

1 · Install the certificate
  1. Open this page in Safari and tap Download profile. Tap Allow.
  2. Open Settings, tap Profile Downloaded near the top, then Install (it will say "Not Verified", that is expected).
  3. Go to Settings › General › About › Certificate Trust Settings and switch on eBilal local CA.
  1. Tap Download certificate.
  2. Open Settings › Security & privacy › More security settings › Encryption & credentials › Install a certificate › CA certificate (wording varies by phone; search Settings for "CA certificate").
  3. Tap Install anyway and choose the ebilal-ca.crt file you downloaded.
  1. Click Download certificate and open the file. Keychain Access opens.
  2. Add it to the System (or login) keychain, then double-click eBilal local CA.
  3. Expand Trust, set When using this certificate to Always Trust, close and enter your password.
  1. Click Download certificate and open it.
  2. Click Install Certificate…, choose Current User, then Place all certificates in the following store.
  3. Browse to Trusted Root Certification Authorities, finish, and confirm the warning.
  1. Download certificate.
  2. Chrome: Settings › Privacy and security › Security › Manage certificates › Authorities › Import, tick "trust for websites".
  3. Firefox (any platform): Settings › Privacy & Security › Certificates › View Certificates › Authorities › Import.
